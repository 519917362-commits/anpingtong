# 安平同城网 - 需求文档

## 项目概述
安平同城网（anpingtong）是衡水市安平县本地分类信息平台，类似 58同城 / 百姓网 / 四川微帮风格的城市门户。

**技术栈：**
- 后端：Node.js + Express + better-sqlite3
- 前端：React + Vite + TailwindCSS
- 管理后台：React + Vite + TailwindCSS
- 数据库：SQLite（文件型）
- 认证：JWT

## 待完成需求 ❌

### 高优先级

#### 1. 图片上传系统
**现状：** 发布信息只能输入文字，无法上传图片
**需求：**
- 支持多图上传（最多9张）
- 图片压缩、缩略图生成
- 存储方案：本地存储 / OSS（阿里云/七牛云）
- 帖子列表显示封面图
- 帖子详情页图片轮播

#### 2. 各分类定制发布表单
**现状：** 所有分类共用同一个发布表单（标题、内容、价格、联系方式）
**需求：**
| 分类 | 定制字段 |
|------|---------|
| 招聘求职 | 公司名称、薪资范围、学历要求、工作经验、招聘人数、工作地址、职位类型（全职/兼职/实习） |
| 房屋租售 | 房源类型（整租/合租/出售）、户型、面积、楼层、装修情况、朝向、配套设施 |
| 二手买卖 | 商品成色（全新/九成新/八成新）、原价、交易方式（自提/快递） |
| 车辆交易 | 品牌型号、上牌时间、行驶里程、车况、过户次数、保险到期 |
| 旺铺转让 | 店铺面积、转让费、租金、行业类型、是否带货转 |
| 寻人寻物 | 丢失时间、丢失地点、物品特征、悬赏金额 |
| 家电数码 | 品牌、型号、购买时间、保修情况、配件清单 |
| 教育培训 | 课程类型、适合年龄、上课时间、机构名称、师资介绍 |
| 家居建材 | 品牌、规格、材质、适用场景、是否包安装 |
| 优惠信息 | 优惠类型（折扣/满减/赠品）、有效期、使用条件、适用门店 |
| 拼车出行 | 出发地、目的地、出发时间、座位数、车型、费用分摊 |
| 促销打折 | 原价、现价、折扣率、开始时间、结束时间、库存数量 |
| 全城知道 | 问题类型、悬赏积分、最佳答案标记 |

#### 3. 用户个人中心
**现状：** 只有"我的发布"页面
**需求：**
- 个人信息管理（头像、昵称、手机号修改）
- 我的收藏
- 我的消息通知
- 实名认证（姓名 + 身份证号 + 人脸识别/身份证照片）
- 会员等级/积分系统
- 我的企业（如果是商家）

#### 4. 信息审核流程优化
**现状：** 发布后直接 pending，后台手动审核
**需求：**
- 自动审核规则（敏感词过滤、图片鉴黄）
- 用户信誉等级（高信誉用户免审核）
- 审核结果通知（站内信/短信）
- 违规处理（下架、封号、黑名单）

#### 5. 付费增值服务
**需求：**
- 信息置顶（按天计费）
- 加急显示（醒目颜色/标签）
- 刷新排名（ bump 到列表顶部）
- 推广套餐（多条信息组合优惠）
- 企业认证（蓝V标识）
-  Banner 广告位投放

### 中优先级

**需求：**

- 导航到信息位置

#### 7. 消息通知系统
**需求：**
- 站内消息（审核结果、回复提醒、系统通知）
- 短信通知（审核通过、新回复）
- 微信模板消息（如接入公众号）
- 消息已读/未读标记

#### 8. 评论与互动
**需求：**
- 帖子评论区
- 评论回复（二级评论）
- 点赞/收藏
- 举报功能
- 私信联系（站内信，不暴露手机号）

#### 9. 数据统计与分析
**需求：**
- 后台数据面板（日活、新增用户、发布量）
- 分类热度统计
- 用户行为分析
- 收入统计（如有付费功能）

#### 10. SEO 优化
**需求：**
- SSR 或预渲染（解决 SPA SEO 问题）
- 动态 meta 标签（标题、描述、关键词）

- 站点地图 sitemap.xml
- 友好的 URL（已部分实现）

### 低优先级

#### 11. 微信小程序
**需求：**
- 微信小程序版本（分享朋友圈、微信登录）
- 公众号关联（菜单跳转、模板消息）

#### 12. 多城市扩展
**需求：**
- 城市切换（当前只有安平县）
- 城市管理员权限
- 城市独立数据

#### 13. 内容安全
**需求：**

- 图片内容审核（阿里云/腾讯云内容安全）
- 反垃圾（验证码、频率限制）
- 用户举报处理流程

#### 14. 第三方登录
**需求：**
- 微信扫码登录
- 短信验证码登录（替代密码）

#### 15. 数据备份
**需求：**
- 数据库定时备份
- 图片备份
- 一键导出数据

## 技术债务

1. **数据库：** 当前 SQLite，用户量大了需要迁移到 MySQL/PostgreSQL
2. **缓存：** 无缓存层，需要 Redis
3. **图片存储：** 本地存储不适合生产环境，需接入 OSS
4. **前端构建：** 需优化打包体积、代码分割
5. **API 文档：** 缺少 Swagger/OpenAPI 文档
6. **测试：** 无单元测试、集成测试
7. **CI/CD：** 无自动化部署流程
